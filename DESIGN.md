# GeoTease design direction

GeoTease should feel like a pocket field atlas brought to life, not a generic game dashboard.

## Tokens

- Atlas paper `#f4f0e7`: the reading surface.
- Fresh sheet `#fffdf8`: raised content.
- Cartographic ink `#17212b`: primary text and controls.
- Ocean `#174b63`: daily play and links.
- Survey red `#d34a36`: pins, active progress, and the primary game action.
- Field green `#347558`: correct answers only.

Fraunces carries place names and editorial headings. Source Sans 3 carries controls and explanatory text. Source Code Pro is reserved for coordinates.

## Layout

Pages use a left-aligned atlas index: compact introductions followed immediately by playable routes. The homepage pairs the product promise with today's route above the fold. Game screens reserve the globe for play and keep clues in one narrow reading column.

## Signature detail

Subtle latitude/longitude rules appear only on daily or map-adjacent surfaces. They communicate the subject without decorative icons or gradients.

## Interaction

Buttons name the next action. Difficulty selects the actual challenge pool; it is never a cosmetic map setting. Progress celebrates return play without loss aversion, countdowns, or coercive streak messaging.
